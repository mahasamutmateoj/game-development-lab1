# Asset sources

The following assets are original local vector artwork created for this Lab01 project:

- `background.svg` — 1280 × 720 space arcade background, with original stars, orbital geometry, framing, and horizon grid.
- `controller.svg` — 180 × 120 transparent game controller icon.
- `rocket.svg` — 150 × 190 transparent rocket icon.
- `star.svg` — 60 × 60 transparent star icon.

All artwork was authored directly as native SVG using simple paths, shapes, and gradients. No downloaded assets, third-party icon packs, fonts, or raster artwork are included in these four SVG files. The design uses no SVG filters.
